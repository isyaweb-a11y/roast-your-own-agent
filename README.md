## The entry

`main.py` writes one original line to `/output/entry.txt` — a roast
of my own AI agent, aimed at its real habit rather than the stock
hallucination jokes:

> Give my agent a one-line task and it returns a moon-landing programme: three subagents, a risk register and a debrief, to boil an egg.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
